# CampusMap API

**CampusMap**.

El objetivo del sistema es permitir a los usuarios:
- visualizar espacios del establecimiento,
- consultar información relevante,
- acceder a recorridos sugeridos,
- y reportar incidencias o barreras de accesibilidad.

---

# Tecnologías utilizadas

- Java
- Spring Boot
- Maven
